# Vehicle Fleet Management System

This project was completed as part of an Object-Oriented Programming (OOP) workout focused on building a vehicle fleet management system in Python. The application contains different vehicle types and demonstrates key OOP principles through a series of connected challenges.

## Completed Challenges

- ✅ Challenge 1: Vehicle Class
- ✅ Challenge 2: FuelTank Encapsulation
- ✅ Challenge 3: Vehicle Inheritance
- ✅ Challenge 4: Electric Car & Polymorphism
- ✅ Challenge 5: Dunder Methods
- ✅ Challenge 6: Fleet Manager

## Key Concepts Practiced

- Encapsulation with private attributes
- Inheritance and code reuse
- Composition using FuelTank
- Polymorphism across vehicle types
- Method overriding
- Python dunder methods (__str__, __repr__, __eq__, __hash__)
- Collection management and iteration

## Challenges Encountered

- Designing class relationships correctly (inheritance vs composition)
- Ensuring object state remains unchanged when operations fail
- Implementing polymorphism for both fuel and electric vehicles
- Managing fleet operations without relying on type checks

## Lessons Learned

This project strengthened my understanding of OOP design by showing how encapsulation, inheritance, and polymorphism work together to create maintainable and extensible software. Building the fleet manager highlighted the benefits of programming to a common interface rather than specific implementations.
